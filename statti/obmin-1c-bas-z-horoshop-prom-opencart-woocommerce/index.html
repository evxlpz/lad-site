Обмін 1С і BAS з Хорошоп, Prom, OpenCart, WooCommerce

Українські інтернет-магазини працюють на різних платформах: Хорошоп, Prom, OpenCart, WooCommerce, Bitrix, власні сайти на Laravel. Облік при цьому часто один — 1С:УНФ або BAS Малий бізнес. Розберемо, як зв’язати їх між собою і що від платформи взагалі залежить.

Що не залежить від платформи сайту

Більша частина автоматизації живе в самому обліку і з сайтом не пов’язана. Рахунок monobank із замовлення, рознесення накладеного платежу NovaPay, Нова Пошта, залишки Приват24 по ФОП, розподіл замовлень між ФОП, чати Viber і Telegram, маржа — усе це працює однаково, на якій би платформі не був сайт. Важливо лише, щоб замовлення потрапляло в 1С.

Що залежить від платформи

Від платформи залежить обмін: як замовлення з сайту потрапляє в облік, як статуси повертаються назад і як оновлюються залишки й ціни. Для цього потрібне API платформи — спосіб, яким сайт і 1С обмінюються даними.

Хорошоп

У Хорошоп є відкрите API з документацією для розробників. Через нього можна забирати замовлення в 1С чи BAS, повертати статуси, передавати наявність і ціни. Типова задача — синхронізація наявності й залишків з товарами з характеристиками, коли інформація йде з обліку на сайт.

Prom.ua

Prom має API для товарів, цін, залишків і замовлень. Обмін з 1С через API дає змогу отримувати замовлення з Prom в облік і оновлювати на Prom наявність і ціни без ручних вивантажень файлів.

OpenCart і WooCommerce

Це платформи з відкритим кодом, тому на сайт можна поставити невелику приймальну частину або працювати через їхнє API. WooCommerce має REST API, через який зазвичай оновлюють залишки й ціни та забирають замовлення.

Bitrix і Laravel

Для Bitrix обмін замовлень, статусів, клієнтів і залишків готовий. Під Laravel та власні сайти серверна частина адаптується окремо — так само, як і під інші платформи.

Як ми підключаємо іншу платформу

Спершу розбираємо, що саме треба передавати: замовлення, статуси, залишки, ціни, клієнтів. Перевіряємо, що з цього дає API платформи. Далі адаптуємо серверну частину хаба обміну під це API, а частина в 1С лишається тією самою. Ціна обміну — від 15 000 грн разово, точна — після оцінки.

Типові помилки

Вивантажувати залишки файлом раз на день — сайт продає те, чого вже немає. Передавати ціну з браузера — її можна підмінити, сума має братися із замовлення на сервері. Обмін без журналу — коли замовлення «не доїхало», ніхто не знає чому. Змінювати основну конфігурацію 1С під обмін — краще розширення.

Часті питання

Чи працюють ваші модулі з сайтом на Хорошоп?

Рахунки monobank, NovaPay, Нова Пошта, ФОП і чати працюють в 1С незалежно від платформи. Обмін замовлень і залишків із Хорошоп адаптується через його API після оцінки.

А з Prom.ua?

Так само: обмін через API Prom адаптується під ваші задачі, решта модулів працює в 1С як звичайно.

Скільки коштує обмін 1С з Хорошоп чи Prom?

Від 15 000 грн разово; точна ціна — після розбору, що саме треба передавати.

Для якої платформи обмін готовий одразу?

Для Bitrix. Під інші платформи — адаптація.
