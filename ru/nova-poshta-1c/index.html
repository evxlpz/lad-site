Что делает модуль

  • Актуальные отделения и почтоматы НП в учете
  • Претензия по посылке в один клик
  • Напоминание клиенту о посылке на хранении

Как это работает

  1. Справочник отделений и почтоматов обновляется из API Новой Почты.
  2. В заказе менеджер выбирает актуальное отделение, без устаревших адресов.
  3. Если посылка потерялась, претензия формируется из данных заказа в один клик.
  4. Когда посылка ждет в отделении, клиент получает напоминание ее забрать.

Что нужно для подключения

  • API-ключ Новой Почты из бизнес-кабинета
  • Канал для напоминаний (бот в Viber/Telegram или SMS) — если нужны напоминания
