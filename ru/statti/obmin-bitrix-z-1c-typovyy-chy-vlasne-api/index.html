Обмен Bitrix с 1С: типовой или собственное API

Типовой обмен сайта с 1С закрывает базовые вещи: каталог, остатки, заказы. Но когда нужны свои статусы, интеграция с ботом, CRM или несколькими системами, он начинает обрастать костылями. Разберем, где граница.

Коротко

Когда хватает типового обмена интернет-магазина на Bitrix с 1С, а когда лучше собственный обмен через API: статусы, клиенты, боты и CRM.

01Что дает типовой обмен

Он передает товары, цены, остатки и заказы в стандартном виде. Для небольшого магазина без нестандартных процессов этого часто достаточно.

02Где он начинает мешать

Сложности появляются, когда нужны нестандартные статусы заказа, частичные отгрузки, несколько способов оплаты со своей логикой, обмен с поставщиком или данные для бота. Каждая такая вещь ломает типовую схему.

03Что такое собственный обмен через API

Это серверная часть на сайте и расширение в 1С, которые общаются между собой по вашим правилам: что и когда передавать, как обновлять статусы, что делать с ошибками. Дополнительно появляется API, которым можно пользоваться из бота или CRM.

04Журнал и ошибки

В любом обмене важно видеть, что именно и когда прошло. Журнал обмена с ошибками экономит часы, когда заказ «не доехал».

05Как делаем мы

Модуль «Хаб обмена» передает заказы с сайта в 1С, возвращает статусы на сайт, синхронизирует клиентов и дает собственное API. Для Bitrix он готов, под Laravel и другие платформы адаптируется.

06Типичные проблемы стандартного обмена

Заказы приходят в 1С с опозданием, потому что обмен идет по расписанию. Статусы из 1С не возвращаются на сайт или возвращаются не все. Обмен падает без объяснений, и ошибку ищут по логам сайта. Большие выгрузки каталога тормозят сайт.

07Что меняется с собственным обменом

Новый заказ идет в 1С сразу после оформления. Менеджер работает в учете, как привык, а смена статуса в 1С возвращается на сайт и клиенту. Ошибки видны в журнале: что, когда и почему не прошло. Через API можно подключить бота, CRM или другой сервис без новых костылей.

08Нужно ли отключать типовой обмен

Не обязательно. Часто типовой обмен оставляют для каталога, а заказы, статусы и клиентов переводят на собственный обмен. Это решение принимается после разбора процессов конкретного магазина.

09Сколько стоит и сколько длится

Модуль обмена сайта с 1С — от 15 000 грн разово. Цена «от», потому что зависит от количества статусов, полей и способов оплаты. Для Bitrix серверная часть готова, под Laravel и другие платформы — адаптируется.
