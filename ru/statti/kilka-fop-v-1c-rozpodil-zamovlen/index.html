Несколько ФЛП в 1С: распределение заказов и лимит

Когда бизнес работает через несколько ФЛП, у каждого свой лимит дохода, свои поставщики и свой счет. Если распределять заказы вручную, ошибки неизбежны: не тот ФЛП, переполненный лимит, путаница в сверках.

Коротко

Как организовать учет и распределение заказов между несколькими ФЛП в 1С: правила по поставщикам, контроль лимита дохода и сверки в одной форме.

01Зачем несколько ФЛП

Причины разные: ограничения дохода для упрощенной системы, разные поставщики, которые работают с разными плательщиками, разделение направлений бизнеса. Учет должен это учитывать, а не заставлять помнить.

02Правила вместо памяти

Вместо «кого сегодня ставить» лучше задать правила: какой ФЛП по какому поставщику, какие лимиты, что запрещено. Тогда при создании заказа 1С сама подставляет нужную организацию.

03Контроль лимита

Когда ФЛП приближается к лимиту, новые заказы должны автоматически переходить на другой по вашим правилам. Конкретные лимиты и условия определяет налоговое законодательство, их нужно уточнять у бухгалтера.

04Сверки и деньги

Стоит видеть в одной форме деньги по каждому ФЛП и сверки с поставщиками, а не собирать эту картину из разных отчетов.

05Что дает модуль

Модуль распределения заказов между ФЛП подставляет правильный ФЛП, заменяет запрещенный или переполненный по правилам, а доступы к деньгам настраиваются отдельно для каждого сотрудника.

06Что бывает без правил

Менеджер ставит ФЛП «как всегда» или «как сказали вчера». Заказ от поставщика, который работает только с одним плательщиком, оформляется на другой ФЛП. Один ФЛП неожиданно подходит к лимиту, а другой почти пустой. Ошибки исправляют уже после отгрузки, с перепроведением документов.

07Как задаются правила

Один раз в форме настроек: какой ФЛП за каким поставщиком, какие ФЛП запрещены для определенных товаров, какие лимиты контролировать. Дальше при создании заказа 1С сама подставляет правильный ФЛП, а запрещенный или переполненный заменяет другим.

08Кто видит деньги

Деньги по ФЛП — чувствительная информация. Доступы настраиваются для каждого сотрудника отдельно: менеджер видит, на какой ФЛП оформлен заказ, а остатки и обороты — только те, кому это нужно.

09Остатки на счетах ФЛП

Если нужно видеть остатки Приват24 по каждому ФЛП рядом с учетом, для этого есть отдельный модуль «Приват24: платежи и остатки» (4 500 грн). Вместе они показывают и нагрузку на ФЛП, и где лежат деньги.
