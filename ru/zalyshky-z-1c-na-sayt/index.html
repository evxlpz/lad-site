Остатки из 1С на сайт автоматически

Наличие товара на сайте берется из учета. Нет товара — сайт это знает, появился — сразу доступен к заказу.

Что сейчас отнимает время

  • Остатки на сайт выгружаются руками
  • Клиенты заказывают то, чего уже нет
  • Сайт показывает «нет», хотя товар на складе

Что делает модуль

  • Остатки из учета на сайт по расписанию
  • Только нужные склады и товары
  • Без ручных выгрузок и файлов
  • Работает с Bitrix, адаптируется под другие платформы

Как это работает

  1. По расписанию модуль собирает остатки с нужных складов 1С.
  2. Отправляет их на сайт.
  3. Сайт обновляет наличие товаров.
  4. Новые поступления появляются на сайте без участия менеджера.

Что нужно для подключения

  • Доступ к сайту для принимающей части
  • 1С с доступом в интернет
  • Bitrix — готово; другие платформы — адаптирую

Да, выбираете склады и группы номенклатуры.
