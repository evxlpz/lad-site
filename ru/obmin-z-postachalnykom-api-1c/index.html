Что сейчас отнимает время

  • Заказы поставщику составляются и отправляются вручную
  • Неизвестно, есть ли товар у поставщика
  • Приходные накладные не сходятся с заказом

Что делает модуль

  • Отправка заказов поставщику из учета
  • Остатки поставщика в учете
  • Статусы и ответы поставщика обратно
  • Журнал обмена с ошибками
  • Адаптирую под API вашего поставщика

Как это работает

  1. Заказ поставщику формируется в 1С, как обычно.
  2. Модуль отправляет его в API поставщика.
  3. Ответ поставщика — подтверждение, остатки — возвращается в учет.
  4. Ошибки обмена видно в журнале: ничего не теряется молча.

Что нужно для подключения

  • API или другой машинный канал у поставщика
  • Соответствие ваших товаров товарам поставщика — настраиваем вместе
  • 1С:УНФ или BAS Малый бизнес (под другие конфигурации — адаптирую)
